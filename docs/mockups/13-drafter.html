# ระบบเวทกระแสธาร
เวทมนตร์ทุกสายดึงพลังจากกระแสธารใต้ดิน แบ่งเป็น 3 ระดับ:
- ระดับผิว — ใช้ได้ทั่วไป เสื่อมเร็ว
- ระดับกลาง — ต้องผ่านพิธี เชื่อมกับ [[ภาคีนักเวท]]
- ระดับลึก — ต้องห้าม เกี่ยวข้องกับ [[วันล่มสลายของหอคอย]]
โน้ต: มังกรไม่ใช้กระแสธาร — พวกเขา "เป็น" กระแสธารเอง
