command inuse

    To test the app.
    - npm start 
    
    to build the app (portable folder -> DraconDexPortable/DraconDex-<version>/).
    - npm run build:portable

    to build the old single-file exe.
    - npm run build:exe

    To install package modules.
    - npm install

    to rebuild module like sqlite.
    - npm rebuild 

    to test from electron check.
    - npx electron .
    - npx electron filename

    to run app build from terminal.
    - "app name.exe"
