# simple"Wywern" layout mode for new comer 
> this feature is part to procress v.4.0.0  
> there are 2 mode going to have in this app after this, 1.simple"Wywern" and 2.standard"Dragon" and simple mode will be default from now. Now standard mode is exists as current layout in v.3.x.x, so after this we are going to create simple layout window named as "Wywern"
  - What should Wywern layout had in the window?
    - first simple layout will only had toolbar as vertical/horizontal as user want, and main area for app that called in v.3.11.0+ as builder.
      - toolbar button included
        - View set button for hub,
          - Nexus nest
          - Sage hut
          - Import dock
          - Import db
        - Import
        - Export
        - Hashtag
        - Color
        - Create module button (under Nexus nest only) > open context menu
          - module list for create (include collector)
    - simple layout will have only one builder page open at the time, so simple's builder don't have split pane.
    - simple's builder tab will open as user want, not open new tab everytime user open an module.
    - simple layout don't have left panel but will do as drill down navigation page that have button on the main page and open drill down as where user go.
