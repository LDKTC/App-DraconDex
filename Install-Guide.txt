  Requirement before start:
    - Flutter SDK 3.44.4 or newer  (https://flutter.dev/docs/get-started/install)
    - Android Studio with Android SDK 24+
    - A phone with USB debugging ON  OR  an Android emulator

Step 1: Go to the flutter_app folder

        cd flutter_app

Step 2: Download all packages

        flutter pub get

Step 3: Check that Flutter and Android is ready

        flutter doctor

    - Make sure Android toolchain shows no red X

Step 4: Test the app on your phone or emulator

        flutter run

    - Connect your phone with USB and allow USB debugging when asked
    - App will launch on your phone

Step 5: Build the APK file

    Option A - Split APK (smaller file, recommended for sharing):

        flutter build apk --release --split-per-abi

    Option B - Universal APK (works on all devices):

        flutter build apk --release

Step 6: Find your APK

    - APK files will be in this folder:

        flutter_app/build/app/outputs/flutter-apk/

    - File names:
        app-arm64-v8a-release.apk   (for most modern phones)
        app-armeabi-v7a-release.apk (for older phones)
        app-release.apk             (universal, larger size)

Step 7: Install APK on your phone

    Option A - USB cable:

        adb install build/app/outputs/flutter-apk/app-arm64-v8a-release.apk

    Option B - File transfer:
        - Copy the APK file to your phone storage
        - Open the APK file on your phone to install
        - Allow "Install unknown apps" if asked

Step last: Transfer your data from PC to phone

    1. Open the PC app and go to the export option in settings
       (or find novel-manager.db in your user data folder)
    2. Copy the .db file to your phone
    3. Open the Android app -> Settings -> Import Database
    4. Select the .db file
    5. All your projects will appear
